## Completed Work

### 1. Database Schema (`backend/database/schema.js`)
Tambah kolom pada tabel `events`:
- `summary TEXT`
- `summary_provider VARCHAR(50)` (ollama/extractive/extractive_fallback/disabled)
- `summary_model VARCHAR(100)`
- `summary_generated_at DATETIME`

Backward-compatible, tidak mengubah clustering.

### 2. AI Service (`backend/services/aiSummarizer.js`)
Baru. Fungsi:
- `summarizeWithOllama` — POST ke `http://localhost:11434/api/generate` (stream=false, temp 0.2, top_p 0.9, num_predict 256)
- `extractiveSummary` — fallback deterministik tanpa dependency
- `summarizeEvent({event, articles, settings})` — 2–3 kalimat per event
- `summarizeTimelineDay({date, events, headlines, settings})` — 1–2 kalimat TL;DR harian

Graceful fallback: error Ollama → extractive.

### 3. AI Routes (`backend/routes/ai.js`)
Protected (`requireAuth`):
- `POST /api/ai/events/:id/summarize` — generate + simpan summary (provider/model/timestamp)
- `POST /api/ai/timeline/daily-summary` — TL;DR harian (body `{date YYYY-MM-DD}`)

### 4. Server (`backend/server.js`)
Mount `/api/ai` routes.

### 5. Events API (`backend/routes/events.js`)
Include `summary` + metadata di list/detail.

### 6. Settings (`backend/routes/setting.js`)
Tambah keys: `ai_enabled`, `ai_provider`, `ai_endpoint`, `ai_model`, `ai_max_tokens`, `ai_temperature` + validators.

### 7. API Client (`frontend/src/services/api.js`)
- `summarizeEvent(id)`
- `summarizeTimelineDay(date)`

### 8. Events UI (`frontend/src/pages/Events.jsx`)
- Tombol "GENERATE SUMMARY" + state loading per event
- Tampilkan block EVENT SUMMARY saat expand (teks + Generated + provider)
- Update state lokal setelah generate (cache).

### 9. Settings UI (`frontend/src/pages/Settings.jsx`)

### 10. i18n (`frontend/src/i18n/index.jsx`)
